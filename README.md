# Surplus Reader

Persönlicher Reader für *Surplus – Das Wirtschaftsmagazin* (für Abonnenten).

- `app/` – die Web-App (zum Home-Bildschirm hinzufügen)
- `scripts/update.py` – holt stündlich Titel, Teaser, Bild-Adressen und Links von surplusmagazin.de (kein Artikeltext)
- `.github/workflows/update.yml` – stündliche Aktualisierung und Veröffentlichung über GitHub Pages

Artikel öffnen sich auf surplusmagazin.de; zum Lesen ist ein Surplus-Abo nötig.
